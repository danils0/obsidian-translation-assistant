Підключення GitHub

Щоб зберігати переклади, створи Fine-grained personal access token. Він має бути обмежений репозиторієм danils0/obsidian-translations і мати лише дозвіл Contents: Read and write.

  1. Відкрий створення Fine-grained token на GitHub.
  2. Resource owner: danils0; Repository access: Only select repositories; вибери obsidian-translations.
  3. У Repository permissions встанови Contents → Read and write. Інші дозволи не потрібні.
  4. Створи токен, скопіюй його та встав нижче.

Токен зберігається лише в пам’яті цієї вкладки, не записується в localStorage і надсилається тільки на api.github.com. Після перезавантаження сторінки його потрібно ввести знову. Не вставляй токен у публічні повідомлення чи файли.
